# UniBE Downloader and Lecture Recorder

Course download and lecture recording tools. See [operational documentation](unibe-downloader_readme.md) for deployment, scheduling, persistence, credentials and recovery.

For updates review and copy only source files to this separate checkout, exclude user files, credentials, live state and logs, run isolated tests and a secret scan, then fast-forward and verify the remote tree. Do not interrupt a recording.

Personal email addresses in this snapshot are replaced by nonfunctional examples. Runtime authentication state, live configuration and captured request samples are intentionally excluded. Review configuration before deployment.
