# ILIAS Crawler Analysis

This directory contains comprehensive documentation and analysis of the ILIAS system at the University of Bern, its authentication mechanisms, OpenCast integration, and the architecture of the automation tools (`crawler` and `unibe-downloader`).

## Contents

- [Architecture](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/architecture.md) - Overview of the automation project architecture.
- [Authentication](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/authentication.md) - Details of the SWITCH edu-ID and Shibboleth SAML flow.
- [ILIAS Objects](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/ilias_objects.md) - Analysis of object types within ILIAS.
- [File Downloads](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/file_downloads.md) - Mechanisms for downloading course materials.
- [OpenCast](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/opencast.md) - Podcast integration and video delivery.
- [Livestreams](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/livestreams.md) - Details of live HLS stream endpoints.
- [Endpoints](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/endpoints.md) - Structured list of observed endpoints.
- [Findings](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/findings.md) - Consolidated findings categorised by evidence level.
- [Hypotheses](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/hypotheses.md) - Unverified assumptions and hypotheses.
- [Improvement Plan](file:///c:/Coding_Local/Ilias_Crawler/ilias_analysis/improvement_plan.md) - Prioritised tasks for the automation tools.
- `samples/` - Contains JSON samples of endpoints and observed requests.

## How to use it
Review the markdown files to understand how the system interacts with ILIAS, OpenCast, and Shibboleth. The `samples` directory provides concrete API data structures.
